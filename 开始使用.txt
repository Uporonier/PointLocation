定点 0.1.0 — iPhone 选点版

交付状态
这是基于 Waypoint 修改的原生 iOS 源码项目，不是已经编译、签名或真机验证的安装包。
当前开发环境是 Windows，没有 Xcode。本次未完成 iOS 编译、视觉运行检查或微信实测。
你的目标设备是截图中的 iPhone 15 Pro / iOS 26.6.1。工程最低版本为 iOS 17.4，
上游声明支持 iOS 26；这不等于已验证你的具体小版本。

本版范围
地图点选、拖动标记、地址搜索、启动模拟、应用新位置、停止模拟。
原生 SwiftUI / MapKit、中文主要界面、蓝色标记、圆角材质卡片、系统深浅色外观。
包含配对导入、LocalDevVPN 引导、连接状态与中断通知、后台维持连接选项。
不包含路线、配速或轨迹功能。底层错误信息部分保持英文，便于排查。
真实设备通信沿用上游实现，不是只在本 App 内移动标记的演示。

方式一：使用 Mac 编译
1. Mac 安装 Xcode 26 或更新版本并完成首次启动，安装 XcodeGen：brew install xcodegen。
2. 在此文件所在目录运行：bash scripts/build-pinpoint.sh
3. 构建成功后得到 build/Pinpoint-unsigned.ipa，仍需签名才能安装。
4. 也可打开生成的 Waypoint.xcodeproj，选择自己的 Signing Team、唯一 Bundle ID，
   连接你的 iPhone，由 Xcode 签名安装。App 在桌面显示为“定点”。

方式二：只有 Windows，使用 GitHub 的 macOS 构建环境
1. 在你自己的 GitHub 新建仓库，将本目录全部文件（包括 .github）放入仓库根目录。
2. 在 Actions 选择 Build Pinpoint unsigned IPA → Run workflow。
3. 构建通过后下载 Pinpoint-unsigned artifact，解压得到未签名 IPA。
4. 使用兼容的 SideStore 或 AltStore 签名安装方案。云端构建可能消耗账户额度。
本次没有为你创建仓库、上传代码或触发远程构建。

首次配置
1. 安装时需要自己的 Apple 签名方式。签名/描述文件有有效期；安装一次并不代表永久可用。
   若希望日常不连接电脑，应选择支持手机端续签的方式并确认它支持你的系统版本。
2. 根据 iOS 的提示启用“设置 → 隐私与安全性 → 开发者模式”，可能需要重启。
3. 安装 LocalDevVPN，并允许它添加 VPN 配置。
4. 使用 idevice_pair 在电脑通过 USB 为此手机生成 RPPairing 配对文件，
   在手机信任自己的电脑，然后把文件传到手机“文件”App。
5. 打开定点 → 设置 → 导入配对文件。不要将配对文件提交到 GitHub 或发给别人。
6. 首次使用 Wi-Fi，在地图选择地点并点“开始模拟”，按向导完成支持文件下载与连接。
配对、支持镜像、VPN 和签名均可能受系统版本影响；失败时不能宣称已适配完成。

微信“发送位置”验收（必须在你的手机完成）
1. 先记下系统版本、微信版本和签名方式。
2. 在定点选择一个容易识别、与真实位置明显不同的地点，启动模拟。
3. 切换到微信 → 文件传输助手 → ＋ → 位置 → 发送位置。
4. 不先搜索或手动选择其他地点，检查地图中心及附近地点是否对应模拟地点。
5. 若结果一致，再自行决定是否发送。发送动作由你操作；本 App 不控制微信。
6. 回到定点换一个地点，重复上述步骤，检查微信是否刷新，而不是继续使用旧位置。
7. 分别检查切后台 1 分钟、5 分钟、锁屏再解锁，以及 Wi-Fi / 移动数据场景。
8. 点击停止模拟，在系统地图和微信重新打开位置页面，检查是否回到真实位置。
9. 任一项失败，记录版本、场景、提示和偏差，不要把 App 内“启动成功”视为微信通过。
中国大陆地图坐标与不同服务之间可能存在偏移，需对照地标实测，不要盲目套用坐标转换。

限制
普通 App 无法要求微信采用某个坐标；系统模拟位置可被其他 App 识别或拒绝。
本项目不保证微信兼容性，不隐藏模拟标识，也未修改微信。
后台挂起、VPN 断开、重启、签名过期都可能中断运行。
停止失败时断开 LocalDevVPN 或重启手机，并确认真实位置是否恢复。
